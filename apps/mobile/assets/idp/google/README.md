# Sign in with Google — bundled artwork

PNG buttons in this folder come from Google’s official asset bundle:

https://developers.google.com/static/identity/images/signin-assets.zip

See **Sign in with Google Branding Guidelines**: https://developers.google.com/identity/branding-guidelines

Files:

- `googleg_48dp.png` — official multicolor **G** product mark from Google (`https://www.gstatic.com/images/branding/product/2x/googleg_48dp.png`). Used on guest landing custom pill only; **do not recolor**.
- `google_continue_dark*` — dark theme, rectangular, **Continue with Google**
- `google_signup_dark*` — dark theme, rectangular, **Sign up with Google**

Do not distort aspect ratio or alter the colored Google “G” when resizing.

### Guest landing (`surface="guestLanding"`)

Custom black pill matches Apple fallback chrome; **`googleg_48dp.png`** (official colors, bundled from Google’s CDN path above) sits beside approved copy strings—**never substitute** a generic monochrome icon or tint this raster.
