# crew-sheet-export

## Entry
crewcue://dev/crew-sheet-export

## Action
From Pace, share a plaintext crew sheet built on device from the loaded schedule.

## API
none. Uses the schedule already on device.

## Permissions
none

## Success
Shows a plaintext crew sheet built on device.

## Empty
Nothing to export.

## Error
Couldn't build the crew sheet.

## Offline
Offline. Crew sheet is ready to share from this device.

## Accessibility labels
- crewcue.crew-sheet-export

## Native SDK pocket
none
