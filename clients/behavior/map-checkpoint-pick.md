# map-checkpoint-pick

## Entry
crewcue://dev/map-checkpoint-pick

## Action
Tap the map to place a checkpoint and save it.

## API
POST /race-rooms/:roomId/checkpoints

## Permissions
none

## Success
Tap the map to place a checkpoint.

## Empty
No checkpoint selected.

## Error
Couldn't save the checkpoint.

## Offline
Offline. Checkpoint placement needs the network.

## Accessibility labels
- crewcue.map-checkpoint-pick

## Native SDK pocket
maplibre
