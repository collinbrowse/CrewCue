# onboarding-notifications

## Entry
crewcue://dev/onboarding-notifications

## Action
Request the platform notification permission during onboarding.

## API
none. The OS permission prompt is the decision.

## Permissions
notifications

## Success
Notification permission is the platform prompt.

## Empty
Notifications are off.

## Error
Notification permission was denied.

## Offline
Offline. Permission is decided on this device.

## Accessibility labels
- crewcue.onboarding-notifications

## Native SDK pocket
push
